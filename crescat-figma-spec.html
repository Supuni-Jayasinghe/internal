Figma Handoff Notes

Setting Up in Figma

  • Create a Local Styles panel with all 14 color tokens from Section 1. Name them using the "/" hierarchy (e.g. Brand/Purple Deep, Text/Ink, Surface/Cream).
  • Create Text Styles for every row in the typography table — name them Display/H1, Heading/H2, Body/Copy, UI/Button, UI/Label, Brand/Logo, etc.
  • Create Effect Styles for the 6 shadow/border tokens in Section 6.
  • Set the Figma canvas background to #F7F5FA (slightly off --cream for visibility).
  • Use Auto Layout for all components. Gap = spacing tokens from Section 3.
  • Set frame width to 1340px for desktop layouts, 768px for tablet, 375px for mobile.

Component Hierarchy (Figma pages)

  • 🎨 Tokens — Color swatches, spacing scale, typography specimens
  • 🧩 Components — All atoms and molecules: buttons, badges, icons, logo, nav, cards
  • 📄 Home — Full desktop home page (1340px frame)
  • 📱 Mobile — Mobile home page (375px frame) with hamburger open state
  • 🔲 Prototype — Linked frames for interactive click-through

Key Measurements to Note

  • Nav height: 76px desktop / 64px mobile — all page content starts below this
  • Hero: 100vh — content padding-bottom 88px to clear the controls bar
  • Controls bar at hero bottom: ~64px tall with frosted glass
  • Section vertical padding: 88px top and bottom (96px for newsletter)
  • Category grid height: 640px desktop, auto on tablet/mobile
  • Dining inset card: positioned -28px bottom, -28px right of main image
  • Logo bar overlaps script by -2px (margin-top: -2px)
